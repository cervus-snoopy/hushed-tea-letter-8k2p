A single-letter entry for the coffee-or-tea prompt, choosing the calmer ritual over the caffeinated habit.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes exactly one character to `entry.txt` inside the output directory.

Python 3 standard library only, no network access, no dependencies to install.
